# 🚆 Smart Railway Sensor Node

## Overview

The Smart Railway Sensor Node is an embedded systems and VLSI-oriented project that demonstrates how intelligent monitoring nodes can be deployed alongside railway tracks to detect abnormal conditions and assist in predictive maintenance.

Instead of building a railway track, this project focuses on designing the electronic monitoring node that could be installed at regular intervals along the railway network.

---

## Objectives

- Monitor vibration using sensors
- Monitor temperature
- Analyze sensor data using Python
- Classify track condition (Normal / Warning / Critical)
- Generate maintenance alerts
- Design Verilog RTL modules for future ASIC implementation

---

## Technologies

- Embedded C
